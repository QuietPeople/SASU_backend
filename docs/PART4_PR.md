# 개인 대시보드와 관리자 통계 조회 추가

기존 DB에 저장된 시청·퀴즈 응답·복습·카드 이벤트를 조회할 개인 대시보드 2개와 관리자 통계·응답 이력 8개 API를 추가한다. 표본이 없는 비율은 null로 반환하고, 최초 영상 퀴즈와 반복 복습을 별도 집계한다. 실제 노출 이벤트 없는 풀이를 노출 수로 계산하지 않는다.

기존 커리큘럼·반응 통계·초기화 기능을 재사용하며 새 테이블·캐시·마이그레이션은 없다. 개인 정보 조회와 관리자 통계를 기존 목업 역할 규칙으로 구분한다.

검증: 기본 테스트 238 통과(별도 환경 필요 178 건너뜀), PGlite PostgreSQL 17.5 기반 DB·HTTP 통합 시나리오 9 통과, 변경 파일 Ruff 통과. Docker PostgreSQL 18/Psycopg 및 다중 연결 경합은 로컬 환경에서 최종 확인해야 한다.

파트1 연결: docs/part1_router_registration.patch로 dashboard와 statistics 라우터를 등록한다. 현재 app/api/router.py는 담당 경계를 지키기 위해 그대로 두었다. 임시 확인은 scripts.part4_preview 진입점으로 가능하다. 신규 STA 경로는 최신 API 취합본과 최종 대조한다.
